Мой выбор пороговых значений:

MIN_OBS = 20 - так как я выявляю аномалии на основе медиан, то если в конкретный день набралось мало запросов, то 
любая случайность может показаться аномалией
MIN_QUERIES = 3 - если будет 1-2 запроса от человека, то аномальными будут все его запросы, а смысл их удалять
ROBUST_Z_THRESHOLD = 3.5 - обычный общепринятый порог z-score в статистике
